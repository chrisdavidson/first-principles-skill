## How this page disciplines its own quantity claims

This page names a class of defect — a hand-written quantity-shaped claim on generated-surface
prose that no gate can dispute — and it is itself hand-written prose on a `docs/` page. The
hazard is explicit and stated before any finding below: containment's sole call site (section 1.2)
reaches only `docs/gates/*.md`, and Phase 25's CONTAIN-01 names three further surfaces, none of
which is this page. A diagnosis that names the class while publishing an uncontained count of its
own would be a fresh instance of exactly what it diagnoses. Four commitments follow from that,
adjudicated at D-02's discretion and resolved toward the researcher's lowest-risk recommendation:

1. **Every quantity on this page is a frozen dated measurement, never a current-fact claim.**
   Each number is stated with the date it was measured and the exact command that produced it, so
   a reader re-derives it rather than trusts it. This is the identical treatment
   [`docs/PROCESS.md`](PROCESS.md) §2 already gives frozen historical counts, and it is legitimate
   here for the same reason it is legitimate there: a census reading is closed and immutable *as
   of its date*, and that is the entire content of what this page claims about any number it
   states.
2. **A moving count this page needs to refer to is pointed at, never restated.** Where the page
   needs the battery total, it names the generated source — `CLAUDE.md`'s generated CI-gate table
   and the population-arithmetic sentence beside it — instead of typing a digit. Where a later
   section needs a gate page's own figures, it names that page's `<!-- GENERATED:FACTS -->` fence
   and the key inside it, never the number the fence currently holds.
3. **The disclosed bound is stated, not discovered by a reader working it out.** This page is not
   a member of `LITERAL_SCAN_MD_GLOBS` (`scripts/gen-gate-docs.py`), so CONF-13's standing literal
   scanner does not scan it; and containment's sole call site is scoped to `docs/gates/*.md`
   (section 1.2), so `detail_page_containment_problems` cannot reach this page either — and could
   not usefully if it did, since this page carries no `<!-- GENERATED -->` fence for a claim to be
   compared against. Nothing gates the digits on this page. That is why commitment (1) is a
   written discipline rather than a checked one, and both halves of the bound were re-derived at
   write time rather than assumed:

   ```
   $ /usr/bin/grep -n "v9.1-claim-containment-diagnosis" scripts/gen-gate-docs.py
   (no output; exit 1 — this page's path is not a LITERAL_SCAN_MD_GLOBS member)
   ```

   Both commands were run 2026-09-09 against the commit named in "Method" below.
4. **The rejected options are named, per D-02.** Two code changes were available and neither is
   taken here, because this phase writes no fix: adding this page to CONTAIN-01's equality floor

## 1. The mechanism

### 1.1 The exemption, quoted at source

`scripts/gen-gate-docs.py` defines `_CITATION_SHAPE_RES`, a tuple of citation/identifier/transition
patterns that `_strip_citation_shaped_numbers` applies before any count claim is extracted from a
page's prose. One member is the measured-transition vector pattern:

```
$ /usr/bin/grep -n "Measured-transition vector" -A3 scripts/gen-gate-docs.py
1140:    # Measured-transition vector, mirroring HEADLINE-LOCK's own
1141-    # arrow-adjacency rule: a digit immediately next to a transition arrow
1142-    # is a delta, not a current-fact count.
1143-    re.compile(r"\d[\d,]*\s*(?:→|-->|->)\s*\d[\d,]*"),
```

The comment block states the pattern's own intent: it mirrors `HEADLINE-LOCK`'s arrow-adjacency
rule (`scripts/check-traceability.py`) — a digit sitting immediately next to a transition arrow
(`→`, `->`, or `-->`) is read as a **delta**, describing a change, not a **current-fact count**
describing the present state of something. **The exemption is correct in intent.** Narrative prose
must be able to say a number moved from one value to another without every one of those numbers
being treated as an unattributed current claim — the alternative would forbid this project's own
`docs/README.md`-style changelog prose entirely. The finding below is that the exemption is wrong
in **extent**, not that it should not exist.

### 1.2 The span-deletion site, and what follows from it

`_strip_citation_shaped_numbers` applies every `_CITATION_SHAPE_RES` member with `pattern.sub(" ",
text)` — a whole-span substitution, not a partial one. For the measured-transition pattern, the
matched span is the **entire** `N → M` run: both operands and the arrow between them, replaced
with a single space before `_normalise_numbers` ever runs to extract candidate count claims from
what remains.

Follow that mechanically, rather than asserting the conclusion: a sentence stating a value's
history is a left-to-right run of hop matches — `152 → 182 → 184` matches the pattern twice,
consuming `152 → 182` as one hop and `182 → 184` as the next. Each match deletes its whole span.
**Every** number in the chain is therefore removed before counting happens, including the
**terminus** — the final value in the chain, positionally last, the one a reader who is not
tracing the regex takes as the sentence's current count. The pattern was written to stop a delta
from being mistaken for a current-fact claim; its side effect is that it cannot distinguish the
terminus (which readers do treat as current) from every hop before it (which they do not).

Containment's reach makes this concrete. `detail_page_containment_problems` is `docs/gates/*.md`'s
containment floor: it splits a page's lines into "inside a generated fence" and "outside" one
(`_generated_line_flags`), strips citation-shaped numbers from both, and reports any number stated
outside a fence with no matching literal inside one. Its **sole call site** is inside `cmd_check()`,
guarded by a `DETAIL_PAGE_DIR in path.parents` test:

```
$ /usr/bin/grep -n "DETAIL_PAGE_DIR in path.parents" scripts/gen-gate-docs.py
2947:        if DETAIL_PAGE_DIR in path.parents:
```

`DETAIL_PAGE_DIR` is `docs/gates/`. This is what scopes containment to the 31 generated detail
pages and nowhere else — a fact section 1.4 below proves by direct invocation, not by reading this
guard and trusting it.

### 1.3 The distinction the exemption destroys

Because the strip removes a stated history's terminus along with every hop before it, containment
cannot tell these two states apart:

**A chain whose final value has gone stale is, to this scanner, bit-for-bit indistinguishable from
one whose final value is current. Both produce the same scanner output: none.**

That sentence is the mechanism-level answer to backlog 999.49's root question, and it is PROSE-01's
own requirement in its own terms: the exemption is not merely under-tested or narrowly missing one
surface, it structurally cannot corroborate a chain's terminus against anything, by the same
whole-span deletion that correctly stops it from flagging the earlier hops.

### 1.4 Proving the blindness on the live tree, by invocation

The claim in 1.3 is demonstrated here against the live tree, not asserted from reading the source.
`scripts/gen-gate-docs.py` was loaded via `importlib`, registered in `sys.modules`, and
`detail_page_containment_problems` was called on `docs/gates/CONF-SURFACE.md`'s live text with the
exact parameters `cmd_check()` passes for a `NARRATIVE_ENTRIES` page (`check_spelled_out=False`,
since `"CONF-SURFACE"` is a `NARRATIVE_ENTRIES` member):

```python
import importlib.util, sys
from pathlib import Path

REPO_ROOT = Path("/home/chrisdavidson/Projects/first-principles-skill")
spec = importlib.util.spec_from_file_location("gen_gate_docs", REPO_ROOT / "scripts" / "gen-gate-docs.py")
mod = importlib.util.module_from_spec(spec)
sys.modules["gen_gate_docs"] = mod
spec.loader.exec_module(mod)

path = REPO_ROOT / "docs" / "gates" / "CONF-SURFACE.md"
text = path.read_text()
check_spelled_out = path.stem not in mod.NARRATIVE_ENTRIES   # False — CONF-SURFACE is a member
problems = mod.detail_page_containment_problems(
    str(path.relative_to(REPO_ROOT)), text, check_spelled_out=check_spelled_out
)
```

**Recorded result, run 2026-09-09 against commit `b937b3c`:** `check_spelled_out=False`;
`problems == []`. Zero containment problems, on the exact page that at this same moment narrates a
`182 → 184` growth history for `_DEFERRED_LEDGER_MAX` (see section 3) while the live constant
reads `181` — a stale terminus, on the page containment is supposed to police, invisible to it.

The same call was then swept across every `docs/gates/*.md` page, deriving each page's own
`check_spelled_out` the way `cmd_check()` derives it (`path.stem not in NARRATIVE_ENTRIES`):
**31 pages scanned, 0 containment problems found across all of them.** Finally,
`python3 scripts/gen-gate-docs.py --check` was run directly and **exited 0**. All three readings
were produced during this plan's own execution against the commit and date named above — not
copied from `24-RESEARCH.md`, which was taken on a different day against a possibly different
tree.

Stated in the voice this finding earns, without softening: the battery was green throughout the
entire period this mismatch existed, and it is still green now. Every one of CR-01, CR-02 and
CR-03 (section 3) was found by a human or a model reading prose, not by any gate. **"The battery
is green" is rejected as evidence about this class.** Where this page needs to refer to the
battery's size, it points at `CLAUDE.md`'s generated CI-gate table and the population-arithmetic
sentence immediately beside it, per this page's own discipline (2) above — never at a typed digit.

### 1.5 The class's own recursion

Four recorded instances of this exact defect were produced *inside the documents that scoped the
fix for it* — not on some unrelated surface, but on the very pages whose job was to study or plan
this class. Naming all four is part of PROSE-01's own requirement, because the property they share
is what turns this from a list of instances into a mechanism-level finding:

1. An apparatus-tier research document commissioned specifically to study this defect class
   stated, as a current fact about the live tree, that the deferred-literal ledger held 182
   enumerated entries — a state that would put the ledger over its own pin (`181`) and fail a
   check that in fact passes. The number was a stale terminus of the same `152 → 182` growth chain
   examined in section 1.4, restated without the arrow that would have exempted it as a delta.
2. The conversation in which this milestone's requirements were drafted restated that same "182"
   as a current figure, propagating the stale terminus one hop further before any file was
   written.
3. `MILESTONE-CONTEXT.md`'s header states a requirement count of "(Count: 14)" against a live
   population this page's own predecessor context measured at 17, and now 18 after PROSE-04 was
   added. That line was left uncorrected on purpose, specifically so this section could account
   for it, and `PROJECT.md` cites that same line as primary evidence for this milestone's own
   thesis — a quantity-shaped claim, wrong on arrival, cited as proof of the class it belongs to.
4. This phase's own context-gathering draft stated that nine tracked Markdown surfaces carry a
   real `<!-- GENERATED -->` fence. That figure came from a keyword search matching the word "cog"
   and prose mentions of "GENERATED" rather than the marker literal itself, and was caught and
   corrected before commit by re-deriving the true count from `_generated_marker_pairs_for` and
   the actual fence text on disk — the real answer is the three named singleton surfaces
   (`CLAUDE.md`, `docs/ARCHITECTURE.md`, `docs/TESTING.md`) plus the `docs/gates/*.md` class, not
   nine.

None of these four sits on a surface any check reaches with a value to compare against — the first
two are apparatus-tier working documents under `.planning/`, which is gitignored and invisible to
a fresh clone (they are described here rather than linked, since a link into `.planning/` would
break VAL-03's link-check against a tree that does not contain it for a fresh reader); the third is
a `.planning/` file whose own content this page cannot link to for the same reason, though its
citation by `PROJECT.md` is a tracked, reachable fact; the fourth was self-corrected only because a
human read the draft before commit, not because any gate caught it. That absence of a comparison
target on every single instance — not any one surface's specific carelessness — is what makes this
a mechanism, not a list.
