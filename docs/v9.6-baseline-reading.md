fresh set," recorded with its N, using INSTR-01..04's columns (parse accounting, HIGH/`?`/
composition counts, the Criterion 5 contradiction entry, and the reference-read booleans), taken

999.137 (which landed ahead of the instrument, leaving a two-hand-scored-capture before-state
instead of columns) and is not spendable twice; this reading is the discharge of it.

**Why this is a tracked `docs/` note.** Per the same D-04 reasoning `docs/v9.6-instrument-rederivation.md`
§1 states for INSTR-01..03, this reading is a tracked `docs/` note in the same family, rather than a
`.planning/` artifact. `.planning/` is gitignored and archived at milestone close; a `docs/` note
survives that archival and stays citable by `docs/requirements-traceability.md` rows for BASE-01
and INSTR-04, and stays re-readable by TRACE-03's citation leg.

**INSTR-04.** This same run discharges the INSTR-04 live reading Phase 50 handed to this phase
(D-14): Phase 50 shipped `_reference_reads_census`/`--reference-reads` at fixture scale only; §3.4
below is the first reading taken over the real capture population.

**Observation discipline.** Per `docs/v8.7-constraint-teardown.md` §2 item 3, a K-of-N reading at
this size is a recorded observation, not a gate — the S-P04 vector swung 2/5 -> 0/5 -> 2/5 across

equals effect. The counts below are one order of magnitude larger (N=32/33) than that citation's
own N=5, but the same discipline applies for the same reason: nothing in this record gates
Phase 52, 53 or 54 — each figure is read as a snapshot in time, not as a threshold cleared or
missed.
