Per-run marker count vector: **`[2, 2, 2, 3, 4]`**. **Every single run clears
`MIN_HEADER_HITS=2`** — unlike the v8.5 generation's vector (`[2, 2, 1, 1, 2]`, where runs 3–4

from a v8.5-style undercount: run5 emits **4 distinct fishbone markers** (its own highest count
of the five runs) **and** 4 composer-structure hits, exactly reaching
`_COMPOSER_FOCUS_CEILING=4`. Per `classify()`'s precedence order, `n==1 AND composer <
CEILING` only holds when composer stays *below* 4; at composer==4 the early-return is
suppressed and the composer-structure override (`composer_structure_hits >= MIN_HEADER_HITS`)
wins, routing the run to `full-composer` even though the fishbone technique's own markers fired
more strongly than on any other run.

Tracing *where* those 4 composer-structure hits come from (via `_composer_structure_hits`'s own
`findall` over the live pattern list against `tests/step0-captures-v8.6/S-P03-run5.txt`) is
essential to reading run5 honestly: they are **3× the `Ground\s+Truths?` pattern** (the
`Ground Truths` section heading plus two later prose uses of "ground truth") **and 1× the bare
`Verdict` pattern** (matched inside the Assumptions-Table column header `| Assumption | Type |
Treatment | Verdict | Verification |`). Runs 1–4 each score `composer_hits=1` from a single
incidental lowercase "ground truth" prose mention and nothing else. Both the `Ground Truths`
section and the Assumptions Table's `Verdict` column are **mandatory parts of the standard
focused-mode output template** (`shared/spine/SKILL-body.md`: under `focused-<technique>`, "All
other phases (Essence, Assumptions, **Ground Truths**, Derivation Chains, …) run as written").
Run5 is, in fact, the *only* one of the five S-P03 runs whose excerpt follows that full template;
runs 1–4 are terser orchestrator-summary narratives that skip the Assumptions Table and Ground
Truths section entirely. So the CEILING did not suppress composer *bloat* here — it suppressed the
one run that most faithfully emitted the agent's own mandated structure, because that structure's
headings incidentally satisfy `_composer_structure_hits`'s `findall`. This is the known
`_composer_structure_hits`-via-`findall` incidental-match fragility already named in this codebase
(the `composer-hits-findall-incidental-match` lesson and the RR-77-08 `CEILING=3→4` calibration
lineage); this phase's D-05 check verified marker *count* but — until this note — not marker
*provenance*.

### Artifact-versus-regression reading

Per D-02: a proven detector-artifact drop (markers WERE emitted but `MIN_HEADER_HITS`-undercounted
or `_COMPOSER_FOCUS_CEILING`-suppressed) is `SUSTAINED (detector-artifact)`; a drop where markers
are genuinely absent is `REGRESSION`. Run5's non-match is unambiguously the former: the fishbone
technique's own marker set is not merely present but at its five-run maximum (4 markers, more
than runs 1–4), and the reason it fails to classify as `focused-fishbone` is entirely the
composer-structure override hitting its ceiling — and, per the provenance trace above, that ceiling
was reached by mandatory template headings (`Ground Truths`, the Assumptions-Table `Verdict`
column) incidentally matching `_composer_structure_hits`'s `findall`, not by an absence of
fishbone-specific content or by genuine multi-technique composer synthesis. If anything the
artifact reading is *strengthened*: run5 is the most template-compliant run, penalised by a
detector fragility rather than by any routing regression. Because the row's overall K/N (4/5) still sits above its 3/5 floor,
this finding does not change the row's disposition (already `SUSTAINED`) — it explains *why*
the row is 4/5 rather than 5/5, and confirms that the one non-matching run is not evidence of
any emission regression from Phase 159's marker-pinned compression. The structural anchor
`fishbone_or_ishikawa` and `people_process_tech` both fire on every run where fishbone fires at
all (4 of 5 runs), consistent with the technique being correctly and robustly identified; the
compression did not narrow marker coverage below the v8.5 generation's own floor.
