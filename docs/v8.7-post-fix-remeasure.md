committed verdict — cites frozen evidence and the offline `--compare` output, computes nothing

This document answers Phase 166's one question: did Phase 165's output-contract fix
(`.planning/phases/165-output-contract-fix/165-SUMMARY.md`) measurably improve output quality,
against the frozen pre-fix baseline this project already had — never a freshly-derived
threshold, never a re-rolled run. `docs/v8.7-correctness-spot-check.md` (Phase 162) is why this
verdict leads with per-defect incidence rather than the aggregate band total: that phase found
rubric conformance does not predict arithmetic/factual correctness in this project's own corpus,
so a rising band score is not, by itself, evidence anything got more *right* — only that it reads
as more structurally conformant to a judge on a given day.

### 3. GOODHART guard

The `--compare` output's computed flag: **`GOODHART_FLAG: clear`.**

Per D-03's guard definition, the signature would be defect counts falling while the mapped bands
(C2/C4/C6) do **not** move. Here, defects did **not** uniformly fall (`untraced` and `verdict` are
flat; only `chain` fell), and the one family that fell (`chain`) is paired with the two bands that
*did* move the most (C4 +5, C6 +3) — not a flat band-sum masking a defect-count drop. The signature
does not fire, and the computed flag agrees: form-without-substance is not what happened here.
This is a negative finding worth stating plainly rather than a positive one to lean on — the guard
being clear does not itself establish that the fix worked; it only rules out this one specific
failure mode.

### 4. NOISE gate

The measured floor from the pre-fix baseline and this run's own same-day arm: **up to ~3 band
points per problem** (Q-P3's within-condition spread, `tests/quality-baseline-v8.7-regenerated/README.md`
§"Within-condition noise floor") and **~+7/108 aggregate or one verdict flip** cross-day
(Phase 164's own reproducibility finding), corroborated here by this run's own **+6/108 same-day
re-anchor drift** (D-02, above) — a second, independent measurement landing in the same order of
magnitude.

Reading each D-03 movement against that floor:

- **`untraced` 6/6→6/6 and `verdict` 5/6→5/6:** zero movement — trivially below the floor; **no
  distinguishable effect**, in either direction, on these two families.
- **`chain` 6/6→4/6 (−2 documents):** a per-document, categorical movement (documents that had a
  malformed chain block now do not), not a band-point movement, so it is not directly commensurable
  with the ~3-point/problem or ~7/108-aggregate floors, which are continuous-score floors. It is
  the one measured movement in the primary metric and is reported as such, with the caveat that
  N=6 documents (three problems × two runs) is a small sample for a categorical count, and no
  floor for *this specific* metric (defect-count reproducibility across judge-days) has been
  separately measured the way the band-score floor has.
- **Aggregate +9/108 cross-day:** **above** the ~7/108 cross-day floor — nominally distinguishable
  from Phase 164's own drift measurement, but not by a wide margin (9 vs. 7 is roughly a 30% margin
  over a floor measured from a single six-document sample).
- **Aggregate +3/108 same-day-anchored:** **below** the ~7/108 floor (and below this run's own
  measured +6/108 same-day drift) — **no distinguishable effect** once judge-day drift is
  controlled for. This is the more conservative and more directly comparable of the two aggregate
  deltas, since it holds the judge-day constant the way the +7/108 floor itself was measured.
