| Score | Definition |
|-------|-----------|
| 1 | Docs-only or purely additive; touches no generated/detector surface (e.g. new `docs/` file, README caveat, root metadata file) |
| 2 | Touches the generation pipeline or a non-detector script/tooling surface (e.g. a new `shared/examples/` file requiring `sync-content.py --write` regenerate) |
| 3 | Larger engineering surface or workflow-file edit; not itself a byte-frozen surface but may conflict with a locked milestone constraint (e.g. builder feature work, a live-spend CI edit) |
| 4 | Ceiling for any invasive change that does NOT touch a byte-frozen surface — no non-frozen-surface item may score 5 |
| 5 | Touches a byte-frozen surface: `shared/spine/SKILL-body.md`, any of the four detector marker counts (pre-mortem 9 / fishbone 7 / inversion 13 / trade-off 10), `MIN_HEADER_HITS`, `_COMPOSER_FOCUS_CEILING`, or any `tests/step0-captures-v*` / `tests/step0-baseline-v*.md` file — reserved exclusively for these; every score-5 row below carries a presumptive-reject verdict per the v8.1 milestone byte-freeze decision |

verdicts (e.g. GROK-16) keep one governing token as the cell's leading word, with the split
explained in the same cell.

**Effort scale:** `{XS, S, M, L, none, N/A}` — `none` = reject-already-done (zero work exists),
`N/A` = blocked/out-of-scope.

Rows are never re-sorted by score or verdict; each sub-table below stays in source read-order
