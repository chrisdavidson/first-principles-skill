| Field | Values |
|-------|--------|
| **Severity** | 3 = user installing/using the final product hits something wrong or misleading (broken install step, false capability claim, wrong skill/example count); 2 = internal surface that could mask drift (stale tooling docs, dangling ledger rows); 1 = cosmetic/hygiene with no user-trust impact |

| **Must-fix flag** | `must-fix` (required before v8.0 ships) / `accept-as-is` (recorded with rationale; no fix required) |
