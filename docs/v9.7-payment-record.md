## 2. The instrument and its scope

The instrument is `wc -w` (and, alongside it, `wc -l`) run on the emitted body, because that
generated file — not the canonical `shared/spine/SKILL-body.md` it is assembled from — is the
surface the model actually reads at runtime. The canonical file is read alongside it as a
cross-check, not as the primary reading. The commands, verbatim, and their output:

```
$ wc -l -w first-principles/agents/first-principles.md
  834 12240 first-principles/agents/first-principles.md
$ wc -l -w shared/spine/SKILL-body.md
  486  9451 shared/spine/SKILL-body.md
```

(`wc -w first-principles/agents/first-principles.md` on its own reports the word column, 12240,
of the combined `-l -w` run pasted above.)

**The instrument's limit, stated plainly, not as a footnote: it measures static shipped prose
only and cannot see runtime output.** `wc -w` counts words present in a file at rest. A
full-composer run's `Techniques not applied:` record — the process-output block PAY-01's Step 0
bullet prescribes — exists only in a model's emitted response at runtime; it is written to no file
`wc` can open, so this instrument never observes it, in either direction. Anything this record
states about a runtime saving rests on section 6's structural argument instead, which is derived
from the body's routing text, not from any word count.

## 6. The runtime saving, argued

**The saving PAY-01 states.** The prior Step 0 text required a `full-composer` run to enumerate
all eight companion techniques in Phase 4, **unconditionally** — every run emitted an
eight-technique walkthrough whether or not any given technique bore on the problem at hand. The
replacement bullet routes each technique to the one phase that owns it and requires only a
one-line decline record, `<technique> — not applicable — <reason>`, for a technique its owning
phase considered and did not apply.

**The routing table this argument rests on**, cited to its two sources in `shared/spine/SKILL-body.md`:
`### Companion tools` (lines 389-464) and Phase 4's Operation paragraph (line 158):

| Technique | Owning phase, as the body states it |
|---|---|
| fishbone | Phase 2 (Challenge Assumptions) |
| inversion | Phase 2 (Challenge Assumptions) |
| five-whys | Phase 3, and the Phase 2/3 boundary (both modes) |
| estimate | Phase 4 (Reason Upward) — named in Phase 4's own Operation |
| theoretical-limit | Phase 4 — named in Phase 4's Operation; also reframes the essence at Phase 1 |
| trade-off | Phase 4 — named in Phase 4's Operation |
| second-order | Phase 4 — named in Phase 4's Operation and its exit criterion |
| pre-mortem | Phase 5 (Validate) |

**The bound this table draws.** Every technique appears in exactly one owning-phase row above, so
a `full-composer` run considers each technique exactly once, at the phase that owns it. The
`Techniques not applied:` record is therefore bounded at **≤ 8 lines per full-composer run** — one
line per declined technique, fewer whenever a technique is applied — never 8 lines per phase and
never 8 × 5. The worst case some readings might assume — every technique reconsidered at every one
of the five phases — is not reachable through this routing, because the table above assigns each
technique to exactly one phase and no other phase's text asks for it again.

**This is an argument from the routing's structure. It is not a measurement, and this section
names itself as an argument, unmissably, so a reader cannot mistake the bound above for a live
reading.** No live turn-cost measurement is claimed anywhere in this milestone, and this phase
takes no live reading of runtime output. Measuring the saving directly would require live
full-composer runs, scored for emitted-output volume, against a pre-PAY-01 copy of the body for
comparison — this phase did not do that, and no task in this phase claims to have done it.

**Relationship to section 2's instrument, stated explicitly.** `wc -w` is static and observes none
of this: it cannot see a `Techniques not applied:` block because that block exists only in a run's
emitted output, never in a file `wc` opens. The word delta recorded in section 3 (+38 words) is
therefore not evidence for anything in this section, and the argument in this section is not
evidence for anything in section 3's word count. A sentence reading "the word count confirms
PAY-01 is cheaper at runtime" would conflate the two claims this record keeps separate throughout
— this record contains no such sentence, and none should be inferred from it.
