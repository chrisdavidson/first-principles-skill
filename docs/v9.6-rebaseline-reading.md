## 1. Scope and standing

**What BASE-02 asks.** Phase 54 requires a second reading, using the identical Phase-50 columns
(INSTR-01..04: the 28 `--detect-defects` columns `analysis_id`..`selfaudit_offvocab_bands` plus
the `--reference-reads` census) BASE-01 (`docs/v9.6-baseline-reading.md`) already took, over the
existing population plus a fresh set, taken after OBS-01..03 (Phases 52 and 53) landed in
`shared/`. This closes the loop Phase 51 opened: BASE-01 was the before-reading, BASE-02 is the
after-reading.

**Two comparisons answer different questions (D-06).** BASE-01's existing population (the 8
directories, 32-scored-of-33-censused captures it read) is frozen output that does not change when
the body changes -- re-scoring it with today's harness can only move if the *instrument* itself
moved, since Phases 52 and 53 added columns and Phase 53's own code review (WR-05..WR-07) changed
the hop-arithmetic parser. So Section 3.1 below reports that comparison labelled **instrument
drift**, never agent change. Section 3.2 through 3.5 instead compare the two fresh sets
(`tests/baseline-reading-v9.6/` before, `tests/rebaseline-reading-v9.6/` after) -- same five
catalog prompts, same transport, same model pin, different body -- which is the milestone's only
before/after that can speak to whether OBS-01..03 changed observable agent behaviour at all, and
even that comparison cannot attribute a difference to the body alone at this N.

**Why this is a tracked `docs/` note.** Per the same reasoning `docs/v9.6-baseline-reading.md` §1
and `docs/v9.6-instrument-rederivation.md` §1 give for their own records, this is a tracked
`docs/` note rather than a `.planning/` artifact: `.planning/` is gitignored and archived at
milestone close, while a `docs/` note survives that archival and stays citable by
`docs/requirements-traceability.md` rows and re-readable by TRACE-03's citation leg.

**Observation discipline.** Per `docs/v8.7-constraint-teardown.md` §2 item 3, a K-of-N reading at
this size is a recorded observation, not a gate -- the S-P04 (five-whys) vector swung 2/5 -> 0/5 ->
2/5 across v7.11, v8.5 and v8.6 with no source change to the technique being measured, meaning at
N=5 noise equals effect. Nothing in this record gates Phase 54's ship plan or any later phase; each
figure below is a snapshot in time, not a threshold cleared or missed.

defect that was always present but was structurally invisible to the Phase-50 instrument (see
`docs/v9.6-instrument-rederivation.md` §7.5/§7.8's disclosed bound on the same detector).

capture's own `.md`/`.jsonl` text is byte-unchanged (`git diff --quiet -- tests/live-conformance-v9.0`

pre-existing defect -- not because the agent's output changed. This is exactly the single delta
