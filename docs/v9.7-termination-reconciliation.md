## 1. Scope and standing

never a reason to withhold it.** Three jobs, executed as plans 01-03 against phase base commit
`54b7516`:

1. Reconcile the surfaces that told a reader to withhold conclusions until a gate was clean, to
   the one-pass bound that already governed the gate elsewhere (TERM-01, TERM-02).
2. Name the Report emission invariant once, where it already lived, and bring four scattered
   degradation-disclosure mechanisms under it (TERM-03, TERM-04).
3. Give Turn discipline a survival priority order and an explicit budget-exhaustion degrade path
   (TURN-01, TURN-02, TURN-03).

TERM-05 was the binding constraint throughout: no new rule. Every edit below cites the existing
sentence it derives from. This record is TERM-05's deliverable — it is not itself an edit to
shipped text, and it invents no rule of its own.

## 4. What changed in `scripts/`, and why

Two files, both under forced necessity rather than by choice — this phase's `scripts/` posture
was already broken by Task 1 of plan 02 before Task 3 of plan 02 made its own edit:

- **`scripts/check-selfaudit-scan.py`** — a **literal pin re-point**. SCAN-GUARD's Body-15 control
  asserts `_count_flat(text, _BODY_DONOTPRESENT_AMENDED) == 1` over the whole emitted agent.
  `_BODY_DONOTPRESENT_AMENDED` held the pre-reconciliation sentence verbatim; reconciling that
  sentence (TERM-03) without re-pointing the pin would have turned SCAN-GUARD — a CI job and a
  battery gate — red. The re-point changed the constant's *value* only: no control, branch or
  count changed (`--describe` reports `branch_count: 100` with an unchanged roster, before and
  after).
- **`scripts/check-loop-closure.py`** — a **comment-only rewrite**. The `_ASK_FALLBACK_MIDRUN`
  rationale comment quoted the pre-reconciliation wording of both `validation-rubric.md:144-145`
  and `SKILL-body.md:378`; after Plan 01 and Plan 02's Task 1 reconciled both, the comment
  described text no longer in the tree. Rewritten to quote the reconciled forms and restate the
  conclusion on stronger ground: the reconciled rules do not merely forbid proceeding best-effort
  past an Absent verdict, they prescribe what replaces it. The constant's value is byte-unchanged;
  every added/removed line in the diff is a `#`-prefixed comment line, confirmed mechanically.

**Decision: option (a), update the stale comment, not leave it as disclosed staleness.** Recorded
in full in `56-02-SUMMARY.md`; reproduced here because it is a `scripts/`-scope decision this
record exists to make auditable. Four reasons: (1) the milestone's "avoid `scripts/`" posture was
already broken by the forced pin re-point in the same commit range, so leaving a second,
provably-stale rationale beside it is strictly worse than fixing it — a planning-time finding
converted into undocumented drift, the exact `56-CONTEXT.md` failure mode; (2) the comment's
conclusion is *stronger*, not weaker, after reconciliation, and should say so; (3) the cost is a
comment — no constant, control, branch or count changed, so `docs/gates/HARN-02.md` needed no
regeneration; (4) D-55-A is not violated — see §5.

## 6. What this phase did not do

- **It did not name PRAOR, the five limbs, Perceive, Observe-as-a-limb, or React.** That
  vocabulary is Phase 57's. The one bounded exception, per the milestone's own decision, is the
  literal label `Observe incomplete — residual caveat` (TURN-02's own requirement text) — used
  here as a caveat-line label only, never defined as a limb, phase or stage. Measured:
  `/usr/bin/grep -rc "PRAOR\|Perceive\|React" shared/ | /usr/bin/grep -v ":0$" | wc -l` returns
  `0`.
- **It registered no gate asserting the Report emission invariant.** Out of milestone scope by
  decision (`56-CONTEXT.md`'s Deferred Ideas); these rows ship audit-only, and this record says so
  rather than leaving that absence to be discovered later.
- **No gate in the tree checks that a given *run* obeys the Report emission invariant** — only
  that the prescription is present and well-formed in the shipped text. `SKILL-body.md` states
  this limit in its own words, adjacent to the self-audit-scan prescription (currently at `:337`,
  shifted from the pre-phase `:327` by this phase's own line insertions): *"This prescription binds
  the emission; no gate in this tree checks that a given run complied with it — a gate can assert
  the prescription is present and well-formed, never that a run obeyed it."* The same limit applies
  to the Report emission invariant this phase named: SCAN-GUARD's Body-15 control proves the
  sentence is present in the shipped agent; it proves nothing about whether an actual analysis run
  disclosed a real degradation.
