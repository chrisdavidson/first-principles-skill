# Fishbone Diagram — Checkout API 503 Errors

## Effect (problem head)
**Checkout API returned 503 (Service Unavailable) for ~40 minutes starting 14:10 UTC, affecting 100% of users.** Database layer ruled out.

The **503** is load-bearing: it signals the service was reachable but couldn't handle requests — typically an upstream/proxy returning it because backends were unhealthy, saturated, or unreachable.
