# First-Principles Analysis: Timed Exams vs. Take-Home Assessments in the AI Era

**Mode:** full-composer (multiple companion techniques requested together; no single focused-technique trigger fires decisively).

---

## 1. Problem Essence

**Core problem:** Given that capable general-purpose AI writing/reasoning assistants can now perform much of the drafting, explaining, and problem-solving labor that unsupervised take-home assessments were designed to elicit from a student working alone, should a university replace timed, proctored written exams with take-home assessments as its default format — and if the right answer is not uniform, along what axis (discipline, level, stakes, task type) should it vary?

**Success criteria:**
1. The final recommendation names a concrete, actionable institutional policy — not "it depends" left unresolved.
2. The recommendation states explicitly which axis (task structure, level, field/licensure status) legitimately changes the answer, as part of the recommendation itself rather than as a hedge.
3. The analysis distinguishes what changed with the arrival of capable AI assistants from what was already true before they existed.
4. The analysis names, with evidence, the equity, integrity, instructor-workload, learning-outcome, and credential-signaling consequences of each option.
5. The analysis states the specific conditions under which the recommendation would flip.

## 2. Assumptions Table

### Supporting work: Fishbone (breadth-first cause categories)

Question brainstormed: *why might a take-home submission fail to reflect the named student's own learning?* Categories used: Student, Tool/AI, Task Design, Institution/Policy, Culture/Norms, Environment/Access (the default six-category set — no domain preset fit better).

| Category | Candidate cause | Discriminating observation |
|---|---|---|
| Student | Time pressure from competing courses pushes toward AI shortcuts | Submission timing clusters near deadline + stylistic discontinuity vs. earlier drafts |
| Tool/AI | Model can complete the task end-to-end in one pass | Task prompt, run unmodified through a current assistant, yields a passing-grade artifact |
| Task Design | Prompt is a static, freestanding artifact with no process requirement | Task has no required draft history, oral component, or in-class stage |
| Institution/Policy | No stated, consistent rule on what AI use is permitted per course | Syllabus language on AI use varies section-to-section within the same course |
| Culture/Norms | Peer norm treats undisclosed AI use as a grey area, not a violation | Informal student surveys report high perceived-undisclosed-use base rates |
| Environment/Access | Unequal AI-tool access or unequal quiet study environment | Usage/subscription data (where available) correlates with SES proxies |

No candidate cause here is new content beyond what the Assumptions Table below formalizes; the fishbone's value is confirming the assumption space has six largely independent entry points, not just "cheating," which is why the table below classifies each entry point separately rather than folding them into one "integrity" line item.

### Supporting work: Inversion (applied to the claim "universities should fully replace timed exams with take-home assessments")

**Claim:** Full replacement of timed exams with take-home assessments improves university assessment.
**Inverted:** Full replacement guarantees a worse outcome.

Failure-guaranteeing conditions enumerated (six, unfiltered):
1. No reliable verification/detection mechanism exists to catch unauthorized AI use, and none is added.
2. AI-tool access is unequal across students and no equalizing measure is funded.
3. Foundational/intro courses are included, so students never build the unaided competence needed to later direct or verify AI output.
4. Tasks are relabeled from in-class to take-home without being redesigned, so the same AI-solvable prompt is now unsupervised.
5. External stakeholders (employers, grad programs, licensure bodies) learn the credential's take-home components are unverifiable, and stop trusting it.
6. Faculty receive no funded redesign time, so implementation is inconsistent across sections of the same nominal course.

Necessary preconditions derived (each a falsifiable claim, tagged load-bearing or not) — these become rows A11–A16 in the Classified Assumptions Table below, since each is an unverified precondition surfaced by inversion rather than a pre-existing belief:

| # | Precondition (must hold for a *full switch* to be safe) | From failure # | Load-bearing? |
|---|---|---|---|
| P1 | A credible non-detector authorship-verification mechanism (oral spot-check, process artifact, staged draft history) exists alongside the switch | 1 | Yes |
| P2 | Institution-funded, equal-access AI provision exists for all enrolled students | 2 | Yes |
| P3 | Foundational/intro-level courses retain unaided-competence verification | 3 | Yes |
| P4 | Task redesign (not mere relabeling) accompanies the format change | 4 | Yes |
| P5 | External stakeholder trust in the credential is actively monitored post-switch | 5 | No (monitoring, not a launch precondition) |
| P6 | Faculty receive funded redesign time proportional to course size/stakes | 6 | Yes |

Every one of P1–P6 is currently unmet at most institutions (see GT-6 below for P2 specifically). This is the direct output the inversion procedure hands back to Phase 2: a full, undesigned switch fails on **four separate load-bearing preconditions at once**, which is a stronger and more specific finding than "cheating might increase." It also does double duty later: P1–P6, satisfied, are exactly the design requirements the recommended hybrid (§6) must meet to work — inversion did not just rule out the naive option, it specified the successor.

## 3. Ground Truths

### Supporting work: reduce-to-primitives (irreducibility drill on "assessment validity")

Claim: *"an assessment format is valid."* Decomposed to its immediate constituents (measurement-theory definitions, each independently stop-testable):
- **Authorship-authenticity** — the observed work product is attributable to the named individual, under known conditions. *Definitional; passes stop test.*
- **Task-construct-relevance** — the task resembles how the certified competence is actually exercised. *Definitional; passes stop test.*
- **Reliability** — scoring is consistent across students and graders. *Definitional; passes stop test.*

All three bottom out at definitions from measurement/assessment theory rather than at a further-reducible claim, so the parent claim "format X is valid" is verified only relative to a stated weighting of these three axes — which is precisely the decomposition chain C1 uses below.

### Ground Truths list

- **GT-1?** Large language models available to any student with internet access (including free tiers of Claude, ChatGPT, Gemini) can generate fluent, structurally competent essay-length prose, code, and worked problem solutions on typical unsupervised assignments within seconds to minutes, at zero or near-zero marginal cost — unverified: this is a widely and easily self-observable capability claim, but no specific benchmark measuring success rate against a representative sample of actual university take-home assignments was opened by this analysis. Verification path: a controlled study scoring current-generation assistants against a stratified sample of real course assignments across disciplines.
- **GT-2?** AI-text detection tools are not reliable enough to serve as sole evidence of misconduct, and carry a documented racial disparity: Common Sense Media (September 2024) found generative-AI detectors had an approximately 20% false-positive rate on Black students' writing vs. approximately 10% for Latino students and approximately 7% for White students; multiple review sources caution against using detector scores as sole grounds for disciplinary action — cited to: Common Sense Media (Sept. 2024); PMC12331776; arXiv:2608.11256; GPTZero 2025 benchmarking post — reported-by-delegate via WebSearch synthesis. A direct WebFetch of the PMC12331776 primary article was attempted and blocked by a reCAPTCHA wall (Phase 3 failure record: source unreachable — automated-access block). Verification path: obtain the Common Sense Media report and a peer-reviewed detector-accuracy study through institutional library access rather than open web fetch.
- **GT-3** A timed, proctored, in-person written exam is an assessment format whose defining structural feature is tight control over production conditions (identity check, restricted time, restricted resource access), which supports the inference that the observed work reflects a specific individual's unaided performance at that moment — definitional; provenance: structural/definitional, passes the irreducibility test as a definition of the format itself (no external citation required for a definition).
- **GT-4** A take-home assessment is an assessment format whose defining structural feature is relaxed control over production conditions (extended/unlimited time, open resource access, no direct observation), in exchange for enabling tasks that resemble how competence is exercised in professional/scholarly practice — definitional; provenance: structural/definitional.
- **GT-5** Contract cheating (paying or arranging for a third party to complete unsupervised assessment work) substantially predates generative AI: a systematic review of 71 samples (54,514 participants, 1978–2016) found a historic average self-reported prevalence of 3.52%, rising to 15.7% in samples from 2014 onward (the essay-mill era, pre-ChatGPT) — source: Newton, "How Common Is Commercial Contract Cheating in Higher Education and Is It Increasing? A Systematic Review," *Frontiers in Education* (2018); read-at-source: article body, quoted directly — "Of the 54,514 total participants, 1919 (3.52%) reported engaging in some form of commercial contract cheating," with the 15.7% figure reported for the post-2014 subsample.
- **GT-6** As of an April 2025 Inside Higher Ed survey of campus chief technology/information officers (conducted with Hanover Research), roughly half of colleges/universities grant students **no** institutional access to generative AI tools; among institutions that do provide access, 27% offer it via an institution-wide license, 13% limit it to specific programs/departments, and 5% provide a custom-built tool; of institutions without access, 36% are considering adding it and 15% are not — source: Inside Higher Ed, "Half of Colleges Don't Grant Students Access to Gen AI Tools" (April 21, 2025); read-at-source: article body, quoted directly.
- **GT-7** Timed testing conditions produce documented anxiety effects not necessarily correlated with subject mastery, and these effects disproportionately burden students with (often unidentified) learning/attention differences: Stanford researcher Jo Boaler's research (2014, as reported by Edutopia) found timed math tests contribute to math anxiety with effects reported to persist long-term, and an estimated 15% or more of students have unidentified learning/attention issues that timed conditions can disadvantage — source: Edutopia, "Tips for Tackling Timed Tests and Math Anxiety," citing Jo Boaler (Stanford); read-at-source: article body, quoted directly.
- **GT-8?** Current LLM-based automated theorem provers solve at most approximately 16.46% of problems on FormalMATH, a 5,560-problem formally-verified Lean4 benchmark spanning high-school-Olympiad through undergraduate-level theorems, and are documented to produce plausible-looking but invalid arguments (omitted cases, invented lemmas) — cited to: FormalMATH benchmark paper (arXiv:2505.02735) — reported-by-delegate via WebSearch synthesis. A direct WebFetch of the primary PDF was attempted and returned unreadable encoded/compressed content (Phase 3 failure record: citation does not support the claim as read — content not extractable from the fetched document). Scope caveat (load-bearing): this benchmark measures machine-formalized (Lean-verified) proof, a narrower and harder task than typical undergraduate "prove this in prose" coursework, where current assistants are known informally to perform considerably better than 16%; this ground truth should not be read as "math homework is AI-safe."
- **GT-9?** University assessment serves two distinct functions that are often conflated: a formative function (feedback that improves the student's own learning) and a summative/signaling function (a credible signal to third parties that a named individual has attained a competence level); these functions can legitimately be served by different assessment designs — foundational, widely-accepted assessment-theory distinction (e.g., formative/summative framing traceable to Black & Wiliam and related assessment-theory literature) — unverified: no specific source was opened by this analysis to confirm exact attribution; flagged for rigor despite being largely uncontested in the field.
- **GT-10?** Oral examinations (vivas, oral defenses) are a long-established assessment format — used, for example, in doctoral defenses worldwide and in some countries' undergraduate traditions — whose defining mechanism is real-time, interactive, adaptive questioning that resists AI substitution because the examinee must produce and defend reasoning live without private drafting-tool access during the exchange — unverified: general institutional knowledge, no specific source opened by this analysis.
- **GT-11?** Several licensure-gated professions (medicine — USMLE/boards; law — bar exam; nursing — NCLEX; several engineering disciplines — the PE exam; accountancy — the CPA exam) require an independently administered, proctored, high-stakes exam as the practice-readiness gate, separate from and downstream of the university degree — unverified: general, well-established public-institutional knowledge, no specific source opened by this analysis.

## 4. Derivation Chains

### Conclusion C1: Neither timed exams nor take-home assessments are unconditionally superior — each buys one validity axis at the structural cost of another

GT-3 (timed exam controls production conditions) + GT-4 (take-home relaxes conditions for authentic tasks)
→ assessment validity decomposes into three independent axes — authorship-authenticity, task-construct-relevance, and reliability — a decomposition drawn from measurement-theory definitions, not from either format's own design choices
→ a timed proctored exam maximizes authorship-authenticity by construction, at the structural cost of task-construct-relevance, because real practice of most competences is rarely closed-book and time-boxed to the degree an exam enforces
→ a take-home assessment maximizes task-construct-relevance by construction, at the structural cost of authorship-authenticity
→ that cost is structural, not incidental, because relaxing time and resource controls is exactly what removes the mechanism that pins the work to a specific individual's unaided effort
→ no format is unconditionally superior across all three axes at once — the right format is whichever axis-tradeoff matches what the specific competence and its stakes require

**Pre-check:** head GT-3, GT-4 · ?-marked: none · lowest cited: none · Inputs ceiling: HIGH
**Confidence:** HIGH — both inputs are clean, unsuffixed, definitional ground truths; every hop follows by direct deduction from the three-axis decomposition; the only two possible rivals ("task-realism always dominates" / "authorship-authenticity always dominates") are both ruled out by the same decomposition, since the two axes are shown to be structurally independent rather than one subsuming the other.

### Conclusion C2: What AI changed is the scale and detectability of an old, already-measured vulnerability — not the emergence of a new kind of vulnerability

GT-1? (current assistants can complete typical unsupervised coursework quickly and cheaply) + GT-5 (contract cheating already measured at 3.52% historic average, rising to 15.7% from 2014, pre-generative-AI)
→ the pre-AI take-home authorship-authenticity problem was already real and measured, bounded mainly by the cost, delay, and paper-trail risk of sourcing a human third party
→ generative AI removes exactly those bounds, since the substitute becomes free, instant, and leaves no external paper trail to a paid provider [Assumes: A17]
→ removing a bound on an already-measured behavior predicts a large increase in the affected population, not the emergence of a qualitatively new integrity category
→ a policy response built only for "a brand-new cheating technology" undersizes the problem — the right framing is that an old, already-tolerated failure mode just lost its main natural limiters

**Confidence:** MEDIUM — GT-1? is unverified as a specific magnitude (it is a widely observable capability, but no representative benchmark against real coursework was read at source); the verification that would remove it as a cause of the downgrade is a controlled study scoring current assistants against a stratified sample of real university assignments across disciplines. Hop 2 rests on `[Assumes: A17]` (removing a bound predicts a scaled increase, holding other deterrents constant); if A17 failed — e.g., a strong cultural/honor-code shift fully offset the removed bound — the endpoint would weaken to "the magnitude of the increase is uncertain" rather than being contradicted, so the chain's direction still stands even if A17's magnitude does not. Rival (scoped, not fully settled): AI-generated work could be treated as a qualitatively distinct violation (non-human origination, no accountable ghostwriter, different IP/hallucination exposure) rather than merely "faster contract cheating"; for this analysis's narrow purpose — the impact on the validity of the resulting grade as a signal of the named student's competence — the practical effect is the same under either framing, so the rival does not unsettle this chain's conclusion, though it may matter for integrity-policy *language* outside this analysis's scope.

### Conclusion C3: AI-text-detector enforcement cannot be the safeguard for a take-home policy, because it trades one failure mode for a worse one

GT-2? (AI-text detectors show racially disparate false-positive rates — ~20% for Black students' writing vs. ~10% Latino, ~7% White — and are not sole-evidence-safe even at best)
→ a policy that relies on AI-detection scores as the primary integrity check will systematically misaccuse an identifiable, protected population at several times the rate of another [Assumes: A18]
→ adopting detector-based enforcement as the safeguard for a full switch to take-home trades a validity problem for a disparate-impact liability problem, which most institutions treat as the more serious institutional failure mode
→ any acceptable policy design must not rely on AI-text-detector scores as the sole or primary mechanism for authorizing punitive action

### Conclusion C4: Switching to an AI-open take-home default is an equity swap, not a clean equity win

GT-6 (institutional AI-access survey: ~half of institutions grant no institutional gen-AI access; only 27% offer a full institution-wide license) + GT-7 (timed testing produces anxiety effects not correlated with mastery, compounding for the 15%+ of students with unidentified learning/attention differences)
→ keeping the timed/proctored default imposes a documented, disability/anxiety-correlated performance penalty on a meaningful share of students
→ switching to an AI-open take-home default without funding universal institutional AI access imposes a different, socioeconomic-status-correlated capability penalty
→ this penalty is not a fringe case, since roughly half of institutions currently provide no institutional AI access at all
→ neither default is equity-neutral on its own — the equity case for switching formats is a trade between an anxiety/disability-correlated harm and a socioeconomic-access-correlated harm, not a straightforward improvement

### Conclusion C5: AI-vulnerability and AI-resistance vary by task structure, not by department identity or "discipline" as a monolith

GT-1? (current assistants complete typical static-artifact coursework readily) + GT-8? (current theorem-provers solve at most ~16.46% of a hard formal-proof benchmark, and produce plausible-but-invalid arguments) + GT-10? (oral exams are a live, interactive, adaptive format)
→ AI substitution risk is lowest for tasks whose correct completion requires real-time, interactive, or genuinely novel production that cannot be drafted in advance and submitted as a static artifact
→ AI substitution risk is highest for tasks whose correct completion is a static artifact resembling common training-distribution content — standard essays, routine problem sets, boilerplate code, literature summaries
→ this risk profile holds regardless of which department nominally owns the course
→ since most departments assign both static-artifact tasks and interactive/novel tasks, a single department-level rule will misclassify at least some of that department's own assessments
→ the correct unit for an AI-era assessment policy decision is the individual task's structure, not the department or the university as a whole

### Conclusion C6: The tolerable amount of take-home authorship risk is field-dependent, on an axis separate from task-type

GT-11? (licensure-gated professions require an independent, proctored, downstream competence exam) + GT-9? (university assessment serves both a formative and a summative/signaling function, which can be served by different designs)
→ in licensure-gated fields, the university's internal course-level assessment format is not the last or only checkpoint verifying individual competence
→ the licensure exam re-verifies that competence independently under controlled conditions
→ in fields without an equivalent downstream external gate, the university's own assessments are the primary verifiable signal of individual competence available to employers and graduate programs [Assumes: A19]
→ for the parts not otherwise independently checked by employers themselves, that university signal is often the only one available
→ the tolerable amount of authorship-authenticity risk in a take-home-heavy design is field-dependent
→ that risk is meaningfully lower, though not zero, in licensure-gated fields with an independent downstream gate, and much higher where the university's own assessment is the only competence signal available

### Companion technique: Trade-off analysis (three candidate policies, plus status quo)

**Options** (status quo named explicitly, per the procedure):
- **Option A — Status quo:** all assessment remains timed, proctored, closed-book by default.
- **Option B — Naive full switch (AI-permitted, no added verification):** all assessment becomes take-home, AI use unrestricted, no new verification layer. **Knocked out** — fails the must-have "a credible authorship-verification mechanism exists for high-stakes work" (chain C2 + Abandoned-Reasoning Dead End 1).
- **Option C — Naive full switch (AI-forbidden, detector-enforced):** all assessment becomes take-home, AI use banned, enforcement via AI-text detectors. **Knocked out** — fails the must-have "no systematic disparate impact without mitigation" (chain C3 + Abandoned-Reasoning Dead End 2).
- **Option D — Tiered hybrid:** timed/proctored (or in-class, closed-book) retained by default for foundational/intro courses and for licensure-adjacent high-stakes checkpoints; redesigned, AI-transparent take-home tasks (with oral spot-checks and/or process artifacts as the verification layer) used for advanced/authentic tasks where task-realism matters more. Passes both must-haves.

## 5. Abandoned Reasoning

### Dead End: Full unrestricted take-home switch (AI-permitted, no added verification)

**What was tried:** Considered as the most direct reading of the question as posed — simply replace timed exams with take-home assessments, university-wide, with no other change.

**Why abandoned:** Fails the trade-off's must-have "a credible authorship-verification mechanism exists for high-stakes work" (chain C2's premise, combined with the absence of any mechanism satisfying preconditions A11/A12/A14). GT-2 shows no reliable detector-based fallback exists either, so there is no cure available within this option as stated.

**What it ruled out:** Saves the analysis from treating "just allow AI on take-homes and grade normally" as a serious standalone contender; any revival of this option must first supply a credible non-detector verification mechanism (A11) plus funded equal access (A12) — at which point it is no longer this option, it is a version of the tiered hybrid.

### Dead End: Detector-based enforcement as the safeguard for a take-home-AI-forbidden policy

**What was tried:** Considered keeping the take-home format but banning AI use, relying on AI-text-detection software (Turnitin/GPTZero-style tools) as the enforcement mechanism.

**Why abandoned:** Chain C3 shows this fails the "no systematic disparate impact without mitigation" must-have — GT-2's documented racial false-positive disparity (~20% vs. ~10% vs. ~7%) means detector-based enforcement creates a new, more serious equity/liability problem than the integrity gap it was meant to close.

**What it ruled out:** Saves the analysis from treating "buy better detection software" as a sufficient policy fix on its own; names the specific reason a purely technical enforcement layer cannot substitute for verification-layer redesign, and confines detector output to a triage-only, human-reviewed role at most (chain C3's live rival).

### Dead End: Department-level (discipline-level) format rules as the policy's unit of decision

**What was tried:** Considered a simpler-to-administer compromise: a rule such as "STEM/math keeps exams, humanities goes take-home," treating discipline as the unit of policy.

**Why abandoned:** Chain C5 shows AI-vulnerability varies by task structure (static-artifact vs. interactive/novel) within virtually every department, not by department identity, so a department-level rule would misclassify a material share of each department's own assessments (e.g., a "protected" math department still assigns AI-vulnerable routine problem sets; a "take-home" humanities department can still run AI-resistant oral defenses).

**What it ruled out:** Saves the analysis from recommending an administratively convenient but structurally mismatched rule; points instead to task-level design guidance, within a discipline/level-tiered frame, as the right grain of policy (folded into the recommended hybrid in §6).

### Dead End: Full re-architecture around AI-augmented-only competence, university-wide

**What was tried:** Considered the strongest rival to the headline recommendation — retiring unaided assessment entirely on the grounds that preserving it is a losing, temporary battle against tools that will only get more capable and more embedded in real work.

**Why abandoned (as a *university-wide, uniform* policy):** Chain C6 shows tolerable authorship risk is field-dependent — licensure-gated fields still require independently verified unaided-under-pressure competence via a downstream exam — so a uniform retirement of unaided assessment is unsafe in those fields specifically. The skill-sequencing concern (A9: directing/verifying AI output well itself requires foundational competence built without heavy AI reliance) further argues against retiring unaided assessment at the foundational/intro level even in fields without a licensure gate.

**What it ruled out:** Saves the analysis from over-correcting into an equally uniform opposite extreme; confirms that what is right about this rival — deliberate, assessed use of AI as an amplifier — is already captured by the recommended hybrid's advanced/authentic take-home tier, rather than requiring a separate, more radical policy.

## 6. Conclusion

**Recommended approach:** Adopt a tiered, task-level hybrid as the default university-wide assessment policy, not a uniform switch to take-home and not an unmodified status quo (chain C7): retain timed/proctored (or in-class, closed-book) assessment by default for foundational/intro courses and for the terminal checkpoints of licensure-adjacent high-stakes fields, and deploy redesigned, AI-transparent take-home tasks — paired with a non-detector verification layer such as oral spot-checks or staged process artifacts — for advanced and authentic-task assessment where task-realism matters more than closed-book recall (chain C1, chain C5). This recommendation is binding only together with its implementation conditions: a credible authorship-verification mechanism (A11), institution-funded equal AI access (A12), retained unaided-competence checks at the foundational level (A13), genuine task redesign rather than relabeling (A14), and funded faculty redesign time proportional to stakes (A16) — precisely the preconditions the inversion procedure derived in §2, which double as this policy's minimum viable design.

**Key insight:** The two default readings of the question are both wrong in the same way. Treating this as "did take-home get newly vulnerable to AI" misses that the vulnerability is old and merely lost its cost/delay/detectability bounds (chain C2) — the right response is to restore an authorship-verification mechanism, not to relitigate the format itself. And treating the right policy unit as "the institution" or even "the discipline" misses that AI-vulnerability tracks individual task structure (static-artifact vs. interactive/novel) within every department, and that tolerable risk separately tracks field-level licensure architecture (chain C5, chain C6) — two independent axes that a single university-wide format rule cannot represent no matter which format it picks.

**Trade-offs acknowledged:** This recommendation deliberately does not deliver a clean equity win — it trades an anxiety/disability-correlated harm for a smaller, differently-distributed socioeconomic-access harm unless institution-funded AI access is genuinely universal, which it is not by default at most institutions today (chain C4). It also does not deliver a workload or administrative saving: redesigning tasks and standing up a verification layer is a real, front-loaded faculty burden that concentrates precisely in the departments least equipped to absorb it without dedicated funding (second-order extension of chain C7), and it introduces a new, achievement-based (rather than access-based) form of student stratification at the advanced tier that this analysis flags but does not resolve (second-order extension of chain C7).

**Conditions that would flip this recommendation** (each names the specific evidence that would change it):
- If a controlled study found current assistants cannot actually complete a representative sample of real coursework at passing quality, the motivating premise weakens and the status quo becomes adequate without redesign (chain C2).
- If low-error, non-disparate-impact AI-detection technology became available and independently verified, Option C's knockout failure would be cured and the trade-off in chain C7 would need to be rescored with detector-enforcement restored as a viable option.
- If institution-funded, universal AI access became the sector norm (closing the gap chain C4 identifies), the equity case for a broader, less-tiered take-home default would strengthen materially, shifting the hybrid's boundary toward more take-home use.
- If a specific field's downstream licensure gate were removed or weakened, that field's tolerable take-home-authorship risk would drop, shifting that field's tier boundary back toward the timed/proctored end (chain C6).
