## Falsifiability

The document acknowledges a specific, checkable boundary condition — country size and density — under which the land-share estimate shifts materially (0.6–2.2% to 3–9%), which is more concrete than a generic disclaimer. But it never states what would overturn the actual headline conclusion ("land is not the binding constraint"); even in its stress-tested worst case it still calls the result "manageable," so no scenario is offered in which the core recommendation would actually be wrong. The self-flagged uncertainty on inputs (density figure, demand multiplier) is also never tied to a threshold — e.g., how far off would the LBNL figure need to be before land *did* become a constraint. That leaves the falsifiability gesture real but incomplete.
