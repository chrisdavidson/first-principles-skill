**What was tried:** Considered recommending that all eight companion-technique procedures be moved out of the always-loaded agent body and into Read-gated reference files uniformly, on the theory that all eight are "auxiliary" and conditionally invoked.

**What it ruled out:** Saves a future reader from treating "the six/eight companion tools" as one bucket for a splitting decision — this analysis's recommendation (O4) explicitly defers that decision to per-technique frequency evidence rather than resolving it uniformly here, because the evidence to resolve it uniformly does not exist in what was inspected.

## 6. Conclusion

**Recommended approach:** Do not split the file as the first move. Narrow scope first: extract the deterministic "Deliver the analysis as a file" publishing pipeline (figure/PDF/index rendering) into an executable script or hook, following the project's own precedent for a sibling concern (chain C2; chain C3). Then re-measure the generated agent artifact's actual token count, redefine the line-count budget around that measurement (not around the hand-maintained source file's line count), and only then decide, technique-by-technique and on real firing-frequency evidence, whether any of the eight companion-technique procedures are worth Read-gating out of the always-loaded body (chain C3).

**Key insight:** The reflexive "split the file" move conflates two independent questions — where instructions physically live, and what the agent is responsible for doing — and in the one real instance inspected, roughly a fifth of the file's length is not reasoning-method content at all but a second, distinct job (document publishing) the agent quietly acquired; that responsibility, not file organization, is the part worth relocating first (chain C1; chain C2).

**Trade-offs acknowledged:** Extracting the publishing pipeline into a script makes it less directly inspectable and editable by a maintainer who only edits markdown and cannot run code, and the recommended re-measurement/redefinition steps add real, if modest, implementation delay before any budget question is resolved (chain C3).
