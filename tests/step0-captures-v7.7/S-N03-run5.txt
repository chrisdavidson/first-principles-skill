## The core weakness
Your error handling guards **content** but not **boundaries**. You carefully catch `JSONDecodeError` when parsing lines, but every input *into* the script — CLI args, the input directory, each file, the output directory — is consumed with zero validation. So real failures produce raw tracebacks instead of clear messages.

## Most likely causes of the startup crash (start here)
1. **Missing `sys.argv[1]`** (line 4) — running with no argument throws `IndexError` instantly. No usage message, no `len()` check.
2. **Wrong working directory** — `sys.path.insert(0, "scripts")` and the `tests/...` paths are relative to CWD, not the script. Run from anywhere else → `ModuleNotFoundError` at import time (the earliest possible crash). Classic "works on my machine."
3. **Output dir never created** — no `mkdir`, so `write_text` hits `FileNotFoundError`.
4. **Missing input file** mid-loop — `read_text` on a missing `.jsonl` crashes partway through, leaving half-written output.
