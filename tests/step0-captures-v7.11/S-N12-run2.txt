## Summary

The agent ran a **focused pre-mortem** (reasoning backward from "the failure already happened"). Its core finding holds even without site specifics: a known drainage deficiency fails through one of **four chains**, and the binding constraint is usually liability, not physics.

**The four failure chains:**

- **A — Foundation undermining** (high confidence): water saturates soil under/against foundations → loss of bearing capacity + hydrostatic uplift → differential settlement, cracked footings, basement wall failure.
- **B — Slope/embankment failure** (high, if a slope exists): drainage fails to relieve pore pressure → effective stress drops → landslide. Fast, catastrophic, life-safety.
- **C — Capacity exceedance & off-site flooding** (most common real outcome): a storm exceeds the deficient system → backup, ponding, uncontrolled discharge onto neighboring property → property loss **plus** regulatory/legal liability.
- **D — Progressive latent degradation** (the dangerous one): chronic saturation + freeze-thaw degrade soils/materials over seasons → failure arrives *after* occupancy, when remediation is far costlier. This is why "it's been fine so far" is a false signal.

**Key second-order insight:** the moment a defect is documented, proceeding without remediation converts an engineering problem into a **negligence/liability problem** — insurer denial, professional liability — which typically dwarfs the remediation cost. So the implicit premise that "proceed" is the cheaper path is likely false.

**Grounded in physical invariants** the agent accepted as ground truth: gravity-driven flow, the effective-stress principle (saturated soil loses shear strength), hydrostatic pressure, finite conveyance capacity, and freeze-thaw cycling.
