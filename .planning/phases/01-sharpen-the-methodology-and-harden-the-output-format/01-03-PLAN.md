From methodology.md (Plan 01): the five phase definitions — Identify Essence, Challenge Assumptions, Establish Ground Truths, Reason Upward, Validate — each with entry/exit criteria, operation, and named artifact. Apply them in order.

From output-template.md (Plan 02): the six fixed sections the analysis document must contain, in order — 1. Problem Essence, 2. Assumptions Table, 3. Ground Truths, 4. Derivation Chains, 5. Plus the notation rules: classified five-column assumptions table; `**GT-N**` / `**GT-N?**` ground-truth IDs; `GT-N + GT-M → [intermediate] → [conclusion]` derivation chains with at least one intermediate; D-07 confidence caveats.

Test-run subject (D-08) — must be a genuinely unresolved design question from this skill build. 01-RESEARCH.md Open Question 3 names three strong candidates; pick exactly one and state it as the Problem Essence:
- (a) "Should Phase 4 (Reason Upward) have any prescribed sub-steps, or should it remain fully free-form?"
- (b) "Should the output template's Abandoned Reasoning section be required or optional?"
- (c) "Should assumption classification use 4 types or allow a 'mixed / uncertain' fifth category?"

Pitfall 3 (too-safe problem): the run must have at least one real dead end, at least one assumption that turns out false or unverified, and a conclusion that was NOT obvious before running the methodology.
