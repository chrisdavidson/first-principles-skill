Follow the canonical procedure shape: Frame (re-state the prospective-hindsight premise before writing anything) → Write (independently list every cause of the failure, silently, before sharing — the independent write prevents anchoring) → Share (surface the list one item at a time, no filtering) → Pattern (identify failure modes that recur across independent responses). Write the procedure as solo-compatible (Claude applies it alone) — group facilitation belongs in Failure modes as a contrast, not as the primary framing. For solo use, instruct re-reading the failure list adversarially ("which of these would I have suppressed in a group?").
    6. `## Example` — a mini-example in the everyday/non-technical domain (D-04). Show the prospective-hindsight framing applied, then a short list of backward-derived failure causes, then the recurring pattern identified.
    7. `## Failure modes` — surface the failure modes for pre-mortem (Claude's discretion; draw from 04-RESEARCH — e.g. forward-looking framing that degrades to a generic risk list, running it too early before the plan has specificity, senior authority present anchoring the room / first-speaker anchoring, treating it as a box-tick rather than acting on the findings).
