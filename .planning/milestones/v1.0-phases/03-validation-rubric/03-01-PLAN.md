The six-section output format (SKILL.md "Output format", output-template.md):
1. Problem Essence  2. Assumptions Table  3. Ground Truths
4. Derivation Chains  5. Abandoned Reasoning  6. Conclusion

The 5 methodology phases and their named artifacts (SKILL.md "Methodology"):
- Phase 1 Identify Essence       → Essence Statement (one sentence + checkable success criteria)
- Phase 2 Challenge Assumptions  → Classified Assumptions Table (cols: Assumption, Type, Treatment, Verdict, Verification)
- Phase 3 Establish Ground Truths→ Ground Truths list (stable GT-IDs, source citations, GT-N? for unverified)
- Phase 4 Reason Upward          → Derivation Chains (GT-N + GT-M -> [intermediate] -> [conclusion])
- Phase 5 Validate               → signed-off analysis (weak links resolved or flagged with confidence caveats)

Notation: `GT-N` verified ground truth; `GT-N?` unverified (untested belief elevated for chain use).
Four assumption types: physical law / current constraint / convention / untested belief.
Honest-depth escape valve: `Nothing material here — [reason]` (heading still required).
Verdict vocabulary: Accept / Challenge / Discard.

Reference-component conventions (from output-template.md, the only fully-authored
reference): NO YAML frontmatter; opens with `# Title` H1 then a block-quote scope
note; H2 for top-level sections, H3 for sub-elements (no deeper); fenced code
blocks with NO language tag for format prescriptions; bold-lead-in bullets
(`- **Term** — definition`) for defined vocabulary; `---` between major sections.
