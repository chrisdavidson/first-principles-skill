Required template sections — fixed order, locked by D-01 / 01-PATTERNS.md:
1. Problem Essence
2. Assumptions Table (classified)
3. Ground Truths (with stable IDs)
4. Derivation Chains
5. Abandoned Reasoning / Dead Ends
6. Conclusion + Confidence Caveats

Honest-depth escape valve (D-01): any section may contain `Nothing material here — [reason]`. The section header must still be present; no section may be omitted.

Assumptions table — five columns (METH-03 + D-06): Assumption | Type | Treatment | Verdict | Verification. Type is one of: physical law / current constraint / convention / untested belief.

Ground Truth ID notation: verified → `**GT-1** [fact] — source: [verification source]`; unverified → `**GT-3?** [fact] — unverified: [reason]` (D-07). IDs are stable once assigned.

Derivation chain format (D-02): `GT-N + GT-M → [intermediate claim] → [conclusion]`. One chain per conclusion, no redundant restatement. Each chain MUST have at least one intermediate step — a chain that goes directly from GT-IDs to conclusion is missing a step (Pitfall 5). The intermediate is a new claim statable from neither ground truth alone.

Confidence caveat rule (D-07): a conclusion whose chain includes a `GT-N?` input inherits a MEDIUM or LOW confidence level stating which unverified input caused the downgrade and what would raise it.
