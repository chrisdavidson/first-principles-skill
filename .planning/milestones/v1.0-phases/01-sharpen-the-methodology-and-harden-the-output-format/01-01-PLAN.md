The 5 phase names (fixed, in order):
1. Identify Essence
2. Challenge Assumptions
3. Establish Ground Truths
4. Reason Upward
5. Validate

Required phase definition block — every phase needs all five fields (01-PATTERNS.md "Phase Definition Block"):
- `**Why this phase exists:**` — rationale (METH-06)
- `**Entry criterion:**` — what must be true before the phase begins (METH-01)
- `**Operation:**` — the concrete action the phase performs
- `**Named artifact:**` — the specific named output the phase produces (METH-02)
- `**Exit criterion:**` — what must be true for the phase to be complete (METH-01)

The 4 assumption types and prescribed treatments — locked by D-06, exactly these, no synonyms, no fifth type:
- physical law → accept as a ground-truth candidate
- current constraint → record what would change it (expiry conditions)
- convention → must be explicitly challenged before use
- untested belief → must be verified or flagged unverified

Stakes-escalation rule (D-06): the higher the stakes of the conclusion resting on an assumption, the more that assumption must be pushed down toward physical law or verified ground truth.

Reason Upward exit criterion (D-05) — AND, not OR: (1) the problem's core question is answered, AND (2) every conclusion offered has a complete derivation chain back to named ground truths.

Named artifacts per phase (suggested, executor finalizes per Claude's Discretion in CONTEXT.md): Phase 1 → Essence Statement; Phase 2 → Classified Assumptions Table; Phase 3 → Ground Truths list (stable GT-IDs); Phase 4 → Derivation Chains; Phase 5 → signed-off analysis.
