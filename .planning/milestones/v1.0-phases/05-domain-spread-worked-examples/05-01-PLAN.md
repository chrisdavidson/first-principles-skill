    Section 2: a 5-row Classified Assumptions Table (Assumption / Type / Treatment / Verdict / Verification). EX-01 has NO genuine unverifiable input — do NOT use the `GT-N?` suffix anywhere in this file.

    Section 4: 3 derivation chains, each `GT-N + GT-M → [intermediate] → [conclusion]` with at least one genuine intermediate step (a new inference not statable from either GT alone): (A) why architecture is not the primary bottleneck, (B) why the database-coupling problem is separable from microservices, (C) what the minimum viable intervention is. Every Conclusion claim must trace to a chain in section 4 — introduce no new claims.
