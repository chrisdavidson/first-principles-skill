## The 5 phases (preview)

1. Identify Essence
2. Challenge Assumptions
3. Establish Ground Truths
4. Reason Upward
5. Validate

For the canonical methodology text, see the v1.2 monolith install at
`first-principles-thinking/SKILL.md` in this repo.
